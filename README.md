# Affiliate Deal Automation Hub

An automated Python pipeline that tracks lowest price deals across major Indian e-commerce stores (Amazon, Flipkart, Myntra, Ajio, Croma, Shopsy, Meesho) and auto-posts verified offers with affiliate links to Telegram Channels.

## Features
- **Multi-platform Scraper:** Scrapes product prices, discounts, and images.
- **Link Converter:** Automatic conversion to Cuelinks / EarnKaro / Amazon Affiliate URLs.
- **Price Log Database:** Tracks lowest historical prices.
- **GitHub Actions Runner:** Automated execution on cron schedule.
